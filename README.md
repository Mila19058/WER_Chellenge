# ReadMe WER_Challenge

### How to set up project

run:
- python -m venv ./venv_wer

To create virtual env

run: 
- source venv_wer/bin/activate

To activate environment

run: 
- pip freeze > requirements.txt

To put installed dependencies into requirements.txt

run:
- pip install -r /path/to/requirements.txt
To install dependencies

run:
- python -m ipykernel install --user --name=venv_wer --display-name "vta_wer"  

To set as kernel for pycharm
